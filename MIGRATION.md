# Migration guide

**Nothing to migrate yet.** This file is here on purpose and it is empty on purpose.

`planvortex` has not had a breaking release. When it does, the upgrade notes go here — one section
per major version, with the change, the reason, and the smallest edit that fixes your code. The
[CHANGELOG](CHANGELOG.md) records *what* changed; this file records *what you have to do about it*.

The file exists from the first commit for the same reason the Node client's does: a migration guide
that is created on the day it is first needed gets written in a hurry, by someone who is already
late, for people who are already stuck.
